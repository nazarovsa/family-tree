# Поиск в радиусе 100 км — рабочий охват

Поручение пользователя от 7 ноября 2026: искать по всем доступным сёлам в радиусе 100 км. Географическая основа — объединение двух кругов по 100 км от Потелича и украинского Девятыра; расстояния по прямой, не по дорогам. Точки GeoNames: Потелич 50.20804,23.54674 (696426), Девятир 50.21429,23.48843 (710060). Нынешняя граница Украины и Польши не ограничивает поиск.

## Что подготовлено

- `settlements-100km.csv`: 3 830 записей класса населённых мест GeoNames — 1 703 UA и 2 127 PL. Это не число отдельных исторических сёл: есть хутора, части поселений, устаревшие названия и возможные дубли. Источник не гарантирует исчерпывающего охвата исчезнувших поселений. Все записи оставлены в очереди, а не объявлены проверенными.
- `agad-298-books.csv`: 460 описаний из официального каталога фонда AGAD 298.
- `archive-candidates-100km.csv`: предварительное сопоставление названий из описаний с географическим списком. Совпадение названия — только кандидат: одноимённые сёла и принадлежность к приходу требуют ручной проверки. Ссылка на галерею получена из каталога, доступность каждого отдельного скана ещё не проверена. Деканат и епархия исключены из автоматического сопоставления.
- Исходные выгрузки GeoNames UA.zip / PL.zip, каталог AGAD и оригиналы новых актов сохранены в `sources/radius-100km/`. Географические данные используются только для поиска, не как свидетельство родства.

## Выполненный первый проход индексов

Geneteka: все приходы в регионах Ukraina, podkarpackie и lubelskie; все доступные годы, точное совпадение выключено, поиск в родителях включён. Каждый регион проверен отдельно по рождениям, бракам и смертям. Это охват индекса, не сплошное чтение всех метрических книг. Региональная выдача шире радиуса; места вне круга не становятся семейными кандидатами автоматически.
